## 一、系统基础配置

### 1.1 系统版本与激活
- 将 **Windows 11 家庭版** 升级至 **专业版**
- 使用 **微软账号** 登录，完成同步（主题、密码、Edge 收藏夹等）

### 1.2 系统更新与驱动
- 检查并安装 Windows 更新至最新版本
- 驱动程序检查更新（建议通过官网或 Windows 更新自动获取）

### 1.3 电源与性能设置
- 电源模式设置为 **“最佳性能”**
- 关闭不必要的开机自启项（任务管理器 → 启动）

### 1.4 隐私与安全
- 按需调整 Windows 隐私设置（定位、广告ID、诊断数据等）
- 设置屏保并勾选“在恢复时显示登录屏幕”，这样当你离开电脑进入屏保后，其他人需要输入你的账户密码才能解锁使用。
- 开启"开发人员模式"（解锁 symlink、免管理员跑 ps1，对 Node/npm 全局装包很重要）
- 显示文件扩展名 + 显示隐藏文件 + 标题栏显示完整路径

## 三、环境变量与配置建议

- 将 `Git`、`Scoop`、`Mise`、`Node.js`、`Java`、`Go` 等路径自动加入系统 PATH
- 将代理地址（如 `127.0.0.1:7890`）配置到 Git 等工具中，便于国内使用加速
- npm,mvn等工具需要配置国内镜像加速访问
- 本地MySQL，redis等统一通过docker-compose管理，不装原生服务
