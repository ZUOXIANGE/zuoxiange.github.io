模块分为两块：
- `scripts/`：纯 PowerShell 本地工具，`check-frontmatter.ps1` 通过正则解析 `content/posts/*.md` 的 TOML front matter（`+++` 包裹），校验 `slug/description/categories/tags` 必填且非空；`setup-hooks.ps1` 将 `core.hooksPath` 指向仓库内 `.githooks` 以启用本地 git hooks。
- `.github/`：GitHub Actions 工作流 + Dependabot 配置。`build.yml` 在 PR→main 上执行 Hugo 构建并复用 `check-frontmatter.ps1`；`deploy.yml` 在 push→main 或手动触发时构建并经由 `actions/deploy-pages@v5` 发布到 GitHub Pages，使用 `concurrency: pages` 避免并发部署；`check-hugo-update.yml` 每周一 cron 检查 `.hugo-version` 与 GitHub Releases 最新版本差异，若新版本更高则用 `peter-evans/create-pull-request@v8` 提交 PR 更新版本号；`.github/dependabot.yml` 每周自动为 `github-actions` 与 `gitsubmodule`（blowfish 主题）创建 PR。
依赖方向单向：CI 调用 `scripts/` 中的脚本，脚本不反向依赖任何 CI 文件。
