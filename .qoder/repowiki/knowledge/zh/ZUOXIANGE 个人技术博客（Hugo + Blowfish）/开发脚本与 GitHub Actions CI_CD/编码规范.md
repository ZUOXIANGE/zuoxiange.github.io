- Hugo 版本由根目录 `.hugo-version` 文件集中声明，CI 通过 `peaceiris/actions-hugo@v3` 的 `extended: true` 自动读取，保证本地与构建环境一致。
- 所有 workflow 在 checkout 步骤设置 `submodules: recursive` 与 `fetch-depth: 0`，确保 hugo 主题子模块可被拉取。
- 构建阶段统一缓存 `resources` 目录并以 `config/**` 哈希作为 cache key，加速重复构建。
- front matter 校验逻辑集中在 `scripts/check-frontmatter.ps1`，各 workflow 通过 `shell: pwsh` 直接复用该脚本而非重复实现。
- 需要写权限的 workflow（如自动升级 Hugo）显式声明 `permissions.contents: write` 与 `permissions.pull-requests: write`，仅授予最小必要权限。
