模块按 Hugo 标准目录组织，职责清晰分离：
- config/_default/：Hugo 站点元数据与主题参数，hugo.toml 定义 baseURL、theme=blowfish、taxonomies（tag/category/author/series）、sitemap、outputs（HTML/RSS/JSON/MD）以及 related 索引权重；languages.zh-cn.toml 提供 zh-cn 语言包（作者信息、链接、日期格式）；menus.zh-cn.toml 声明 main/footer 两个导航区；params.toml 集中 Blowfish 主题开关（首页 profile 布局、文章/列表/Taxonomy 视图开关、search/code copy/a11y 等）；markup.toml 为渲染器配置。
- content/：纯 Markdown 内容，posts/ 存放技术文章，notes/ 存放备忘（含 _index.md），about.md 为静态介绍页。
- archetypes/default.md：新页面脚手架，预设 draft=true、title/slug/description/categories/tags 等 front matter。
依赖方向单向：content 通过 front matter 使用 theme 暴露的参数（如 series、showDate 等），config 不反向引用 content。
