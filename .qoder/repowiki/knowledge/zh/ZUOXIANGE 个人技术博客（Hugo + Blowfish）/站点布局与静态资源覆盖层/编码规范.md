- 站点级覆盖通过在 layouts/_default 或 layouts/partials 下放置同名文件来覆盖主题默认实现，而非修改 themes/blowfish 源码。
- JS 逻辑以 IIFE 形式内联在 partial 中，并通过 document.readyState 判断 DOMContentLoaded 时机，避免重复初始化。
- CSS 同时维护 .dark 变体规则，使用 Tailwind 语义色变量（如 --color-neutral、--color-primary-*）保证明暗主题一致。
- 可插拔扩展点通过 templates.Exists 检查（如 extend-footer.html）后再 partialCached 调用，使站点可选择性启用自定义片段。
