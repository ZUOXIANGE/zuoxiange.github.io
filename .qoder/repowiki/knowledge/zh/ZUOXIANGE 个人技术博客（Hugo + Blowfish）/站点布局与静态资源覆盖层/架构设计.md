模块分为两层：
- `layouts/`：Hugo 模板覆盖层。`_default/single.md` 定义站点级 MD 输出格式（仅输出中文标题 + RawContent，供「下载本文」使用）；`partials/` 下按功能拆分 partials——`article-meta/basic.html` 覆盖主题同名 partial 并在 meta 行右侧追加 Markdown 下载链接；`footer.html` 注入 mermaid fenced 渲染、mediumZoom 与 `extend-footer.html` 钩子；`comments.html` 通过 MutationObserver 监听 `html.dark` 类同步 giscus 主题；`toc.html` 实现滚动高亮与折叠的 TOC；`related.html` 复用主题卡片组件。
- `assets/`：静态资源覆盖层。`css/custom.css` 重写 Chroma 配色为 VS Code Light+/Dark+，并新增 `.highlight-wrapper`、`.codeblock-title`、`.mermaid-zoom-*` 等样式；`js/mermaid.js` 覆盖主题默认初始化，增大字号与 flowchart 间距；`img/` 存放站点图片。
依赖方向单向：模板 partials 引用 assets 中的 JS/CSS，不反向依赖业务逻辑；所有覆盖均通过 Hugo 的 partial 覆盖机制与资源管道（Concat/Fingerprint）完成，避免直接修改 themes/blowfish。
