仓库以 Hugo 静态站点为核心，按职责拆分为三个子模块：`site_content_and_config` 提供 `config/_default/` 与 `content/` 下的文章与备忘；`site_layouts_and_assets` 在 `layouts/partials/` 与 `assets/css/custom.css` 中覆盖主题组件而不触碰 `themes/blowfish/`（submodule）；`dev_scripts_and_ci` 通过 `.github/workflows/build.yml` / `deploy.yml` 与 `scripts/check-frontmatter.ps1` 把 front matter 校验与构建检查串联到 PR 与 main 分支。三者共享同一份 Hugo 配置与内容契约：front matter 必填字段（slug/description/categories/tags）由 pre-commit hook 与 CI 双重强制执行，`.hugo-version` 锁定 Hugo 版本保证本地与 CI 一致，Blowfish 主题作为 git submodule 统一被所有子模块引用。
